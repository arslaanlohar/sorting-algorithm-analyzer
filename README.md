# 📊 Sorting Algorithm Analyzer

A web-based application to visualize and compare different sorting algorithms with interactive animations.

## 🚀 Features

- Generate random arrays
- Visualize sorting algorithms
- Bubble Sort
- Insertion Sort
- Adjustable array size
- Adjustable animation speed
- Clean and interactive user interface
## 🛠️ Technologies Used

- Python
- Matplotlib
- Git
- GitHub
